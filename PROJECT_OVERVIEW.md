### `def MvPolynomial.hasseCoeff`
- **Type**: `{σ : Type*} → (d k : σ →₀ ℕ) → ℕ`

#### `def MvPolynomial.hasseDeriv`

### `def MvPolynomial.hasseDeriv`
- **Type**: `{σ R : Type*} → [CommSemiring R] → (d : σ →₀ ℕ) → MvPolynomial σ R →ₗ[R] MvPolynomial σ R`
- **What**: The multivariate Hasse derivative `Δ_d`, the `R`-linear map with `Δ_d (a X^k) = binom(k, d) a X^(k - d)` (zero unless `d ≤ k`); over a `ℚ`-algebra it is `(∏ j (d j)!)⁻¹ ∏ j ∂_j^(d j)`.
- **How**: `Finsupp.lsum R (fun k ↦ (monomial (k - d)).comp (LinearMap.lsmul R R (hasseCoeff d k : R)))` precomposed with `AddMonoidAlgebra.coeffLinearEquiv R`, i.e. extend the monomial rule linearly; key API lemma `hasseDeriv_monomial` is proved by `simp [hasseDeriv]`.
- **Hypotheses**: `[CommSemiring R]` (section variable); no other hypotheses.
- **Uses from project**: `MvPolynomial.hasseCoeff`
- **Used by**: Roth/HasseDeriv.lean (all lemmas from `hasseDeriv_monomial` to `factorial_smul_hasseDeriv_single`, ~60 occurrences); Roth/CoeffNorm.lean (`abs_coeff_hasseDeriv_le`, `normOne_hasseDeriv_le`, generalised-Wronskian degree/coefficient bounds l.247-265); Roth/GenWronskian.lean (`genWronskian` l.34, `kronHasse` l.146, l.241-245); Roth/Index.lean (l.63, l.70, taylor/index lemmas); Roth/Taylor.lean (l.103-105, coefficient of `taylor` as `eval α (hasseDeriv d P)`); Roth/Separation.lean (l.147-148); Roth/Theta.lean (l.378-383); Roth/MainLemma.lean (27 occurrences, l.362-745); Roth/Main.lean (l.385, l.392). #### `theorem MvPolynomial.hasseDeriv_monomial`

### `theorem MvPolynomial.hasseDeriv_monomial`
- **Type**: `∀ {σ R : Type*} [CommSemiring R] (d k : σ →₀ ℕ) (a : R), hasseDeriv d (monomial k a) = monomial (k - d) ((hasseCoeff d k : R) * a)`
- **What**: The Hasse derivative `Δ_d` sends `a X^k` to `binom(k, d) a X^(k - d)`, where `binom(k, d) = ∏ j (k j).choose (d j)`; the defining equation of `hasseDeriv` on monomials. Tagged `@[simp]`.
- **How**: `simp [hasseDeriv]` unfolds the `Finsupp.lsum` / `AddMonoidAlgebra.coeffLinearEquiv` composition and evaluates it on a single monomial (`Finsupp.lsum_single`-style simp).
- **Hypotheses**: `[CommSemiring R]` (section variable); none else.
- **Uses from project**: `MvPolynomial.hasseDeriv`, `MvPolynomial.hasseCoeff`
- **Used by**: `MvPolynomial.coeff_hasseDeriv` (Roth/HasseDeriv.lean:94), `MvPolynomial.hasseDeriv_C` (Roth/HasseDeriv.lean:127), private `MvPolynomial.hasseDeriv_monomial_mul` (Roth/HasseDeriv.lean:233), private `coeff_taylor_monomial_single_add_aux` (Roth/Taylor.lean:111, 116); also available as a simp lemma project-wide.
- **Visibility**: public
- **Lines**: 66–68, proof length 1 line
- **Notes**: Name matches mathlib's univariate `Polynomial.hasseDeriv_monomial` (`hasseDeriv k (monomial n r) = monomial (n - k) (↑(n.choose k) * r)`), so the multivariate statement is uniform with it.

#### `theorem MvPolynomial.hasseDeriv_apply`

### `theorem MvPolynomial.hasseDeriv_apply`
- **Type**: `∀ {σ R : Type*} [CommSemiring R] (d : σ →₀ ℕ) (P : MvPolynomial σ R), hasseDeriv d P = ∑ k ∈ P.support, monomial (k - d) ((hasseCoeff d k : R) * P.coeff k)`
- **What**: Expands the Hasse derivative `Δ_d P` as the sum, over the monomials `a_k X^k` of `P`, of `binom(k, d) a_k X^(k - d)`.
- **How**: `simp [hasseDeriv, sum_def]`: unfolds the `Finsupp.lsum ∘ₗ AddMonoidAlgebra.coeffLinearEquiv` definition and rewrites the resulting `Finsupp.sum` with `MvPolynomial.sum_def`. The statement is in fact definitional (closes by `rfl`, see Evidence).
- **Hypotheses**: `[CommSemiring R]` (section variable); none else.
- **Uses from project**: `MvPolynomial.hasseDeriv`, `MvPolynomial.hasseCoeff`
- **Used by**: `MvPolynomial.normOne_hasseDeriv_le` (Roth/CoeffNorm.lean:151); no other occurrence in `Roth/`.
- **Visibility**: public
- **Lines**: 73–75, proof length 1 line
- **Notes**: Name and shape mirror mathlib's univariate `Polynomial.hasseDeriv_apply` (`hasseDeriv k f = f.sum fun i r => monomial (i - k) (↑(i.choose k) * r)`, Mathlib/Algebra/Polynomial/HasseDeriv.lean:62). The project states it with an explicit `Finset` sum over `P.support` rather than the `Finsupp.sum` form; both are `rfl`-equal.

#### `theorem MvPolynomial.hasseCoeff_eq_zero_iff`

### `theorem MvPolynomial.hasseCoeff_eq_zero_iff`
- **Type**: `∀ {σ : Type*} (d k : σ →₀ ℕ), hasseCoeff d k = 0 ↔ ¬d ≤ k`
- **What**: The multi-index binomial coefficient `binom(k, d) = ∏_{j ∈ supp d} (k j).choose (d j)` vanishes exactly when `d ≰ k` (componentwise order).
- **How**: One `simp` call unfolding `hasseCoeff` and `Finsupp.prod`, then `Finset.prod_eq_zero_iff`, `Nat.choose_eq_zero_iff`, `Finsupp.le_iff`, `not_forall`.
- **Hypotheses**: none (the section `[CommSemiring R]` is not included in the statement).
- **Uses from project**: `MvPolynomial.hasseCoeff`
- **Used by**: Roth/HasseDeriv.lean: `coeff_hasseDeriv` (l.99), `hasseDeriv_C` (l.127); Roth/Taylor.lean: `coeff_taylor_monomial_single_add_aux` (private, l.113)
- **Visibility**: public
- **Lines**: 80–82, proof length 2 lines
- **Notes**: Not `@[simp]`. Stated in the negative form `= 0 ↔ ¬ …`; the positive form `≠ 0 ↔ d ≤ k` (mirroring `Nat.choose_ne_zero_iff`) is a better simp normal form (see Phase 5.5).
