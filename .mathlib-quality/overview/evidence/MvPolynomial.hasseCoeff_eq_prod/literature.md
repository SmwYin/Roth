## Literature summary

Concept: multiindex binomial coefficient; identity-padding of finite products. Sources agree on coordinatewise products in finite variables; support-restricted forms omit coordinates whose lower order is zero because each missing factor equals one. The standard abstract product principle needs a zero-valued finitely supported input, a commutative multiplicative target, and a factor function sending zero to one. An arbitrary upper function suffices; requiring its finite support is unnecessary. Arbitrary index types admit a product over any chosen finite superset of the lower support, whereas the literal full `∏ j` expression uses a finite-type enumeration. None of the found operator generalizations changes this scalar identity. The current theorem agrees mathematically with the finite-variable standard, while its representation restriction on the upper input can be widened after expanding the project alias.
