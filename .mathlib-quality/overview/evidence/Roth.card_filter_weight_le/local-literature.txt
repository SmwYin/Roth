1050: \begin{lem}\label{roth:lem8}
1051:     If $m\geq1$, $r_1, \dots, r_m$ are positive integers and $\lambda>0$, then the number of $m$-tuples of integers $(j_1, \dots, j_m)$ that satisfy
1052:     $$
1053:     0 \leq j_1 \leq r_1, \dots, 0 \leq j_m \leq r_m, \quad \frac{j_1}{r_1}+ \cdots + \frac{j_m}{r_m} \leq
1054: \frac{m-\lambda}{2}
1055:     $$
1056:     does not exceed
1057:     $$
1058:     2 m^{1/2} \lambda^{-1} (r_1 + 1) \cdots (r_m+1).
1059:     $$
1060: \end{lem}
1061: \begin{proof}
1062: We will prove the result by induction on $m$. If $m=1$, we need to estimate the number of integers $j_1$ satisfying
1063: $$
1064: 0 \leq j_1 \leq r_1, \quad j_1 \leq \frac{1}{2}(1-\lambda)r_1.
1065: $$
1066: If $\lambda > 1$ then we have no such $j_1$. If $0<\lambda\leq1$, then the number of $j_1$ from the first inequality is at most $r_1 + 1$, and this number is less than $2 \lambda^{-1}(r_1+1)$, establishing the case of $m=1$.
1067: 
1068: Now suppose $m >1$ and assume that the result is true for $m-1$. If $\lambda \leq 2m^{1/2}$ then the result is trivial, for in this case
1069: $$
1070: 2m^{1/2}\lambda^{-1} (r_1 +1)\cdots (r_m+1) \geq (r_1 +1)\cdots (r_m+1)
1071: $$
1072: and the latter is equal to the number of solutions of $(j_1, \dots, j_m)$ satisfying
1073: $$
1074:     0 \leq j_1 \leq r_1, \dots, 0 \leq j_m \leq r_m.
1075:     $$
1076: 
1077: So we assume $\lambda > 2 m^{1/2}$. For a fixed value of $j_m$, the induction hypothesis is applied to $j_1, \dots, j_{m-1}$ in the following way:
1078: $$
1079:     0 \leq j_1 \leq r_1, \dots, 0 \leq j_{m-1} \leq r_{m-1}, \quad \frac{j_1}{r_1}+ \cdots + \frac{j_{m-1}}{r_{m-1}} \leq
1080: \frac{m-1-\lambda'}{2}
1081:     $$
1082:     where $\lambda'$ is chosen so that
1083:     $$
1084:     \frac{m-1-\lambda'}{2}=\frac{m-\lambda}{2}-\frac{j_m}{r_m},
1085:     $$
1086:     i.e., $\lambda' = \lambda - 1 + 2 j_m/r_m$. We note that $\lambda' > 0$. This is because
1087:     $$
1088:     \lambda' = \lambda - 1 + 2 j_m/r_m > 2m^{1/2}-1 > 0.
1089:     $$
1090:     By the induction hypothesis, the number of $m-1$-tuples is at most
1091:     $$
1092:     2(m-1)^{1/2} (\lambda')^{-1} (r_1+1)\cdots(r_{m-1}+1).
1093:     $$
1094:     Summing these bounds over $0\leq j_m\leq r_m$, it is enough to show
1095: \[
1096: 2\sqrt{m-1}\prod_{i=1}^{m-1}(r_i+1)
1097:  \sum_{j_m=0}^{r_m}\frac1{\lambda-1+2j_m/r_m}
1098:  \leq\frac{2\sqrt m}{\lambda}\prod_{i=1}^{m}(r_i+1).
1099: \]
1100: To finish the proof of the lemma we prove the following statement: Let $r\geq1$ and $m\geq2$ be integers and suppose $\lambda>2\sqrt m$. Then
1101: $$
1102: \sum_{j=0}^r (\lambda -1 + 2j/r)^{-1} < \lambda^{-1} (m-1)^{-1/2} m^{1/2} (r+1).
1103: $$
1104: There are two cases. If $r$ is even, we replace $j$ by $\frac{1}{2}r+k$ to obtain the sum
1105: $$
1106: \sum_{k=-r/2}^{r/2} (\lambda + 2k/r)^{-1} = \lambda^{-1} + \sum_{k=1}^{r/2} 2\lambda (\lambda^2 - 4k^2/r^2)^{-1}
1107: $$
1108: $$
1109: \leq \lambda^{-1} + \sum_{k=1}^{r/2} 2\lambda (\lambda^2-1)^{-1}
1110: $$
1111: $$
1112: \leq (r+1)\lambda^{-1}(1-\lambda^{-2})^{-1}.
1113: $$
1114: Now
1115: $1-\lambda^{-2}>1-1/(4m)>\sqrt{1-1/m}>0$.
1116: For the middle inequality, square the positive quantities and use
1117: $(1-1/(4m))^2-(1-1/m)=1/(2m)+1/(16m^2)>0$.
1118: Taking reciprocals gives the result for even $r$.
1119: If $r$ is odd, we obtain
1120: $$
1121: \sum_{k=0}^{(r-1)/2} \left(\frac{1}{\lambda - \frac{1+2k}{r}}+  \frac{1}{\lambda + \frac{1+2k}{r}}\right)
1122: = \sum_{k=0}^{(r-1)/2}
1123: \frac{2\lambda}{\lambda^2 - \left(\frac{1+2k}{r}\right)^2}
1124: $$
1125: $$
1126: \leq \sum_{k=0}^{(r-1)/2}
1127: \frac{2\lambda}{\lambda^2 - 1}= \frac{r+1}{2}\cdot \frac{2\lambda}{\lambda^2 - 1} = \frac{\lambda^{-1}(r+1)}{1-\lambda^{-2}}.
1128: $$
1129: The rest of the argument is as before.
1130: \end{proof}

1139: \section{The main lemma: Roth's Lemma 9}
1140: Let $\alpha$ be an irrational real algebraic number and let $\kappa\in\R$. Suppose there are infinitely many pairs of integers $h,q$ with $q>0$ such that
1141: \begin{equation}\label{roth:eq1}
1142: \left| \alpha - \frac{h}{q}\right| <\frac{1}{q^\kappa}.
1143: \end{equation}
1144: \begin{thm}[Roth]
1145:     Under the above conditions, $\kappa \leq 2$.
1146: \end{thm}
1147: \begin{lem}
1148:     If the theorem fails, then it also fails for an irrational real algebraic integer.
1149: \end{lem}
1150: \begin{proof}
1151: Suppose the theorem fails for a real irrational algebraic number $\alpha$: there is a $\kappa>2$ such that Equation \eqref{roth:eq1} holds for infinitely many integer pairs $h,q$ with $q>0$.
